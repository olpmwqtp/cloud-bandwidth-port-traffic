## 国外大带宽云服务器的“带宽”到底指什么

指端口速率，也就是这台机器网卡在理想条件下的峰值吞吐，不等于你能 7×24 跑满的速率。真正约束用量的是月流量配额，超出之后按产品规格限速，不额外计费。

把常见配额折算成“平均持续速率”，数量级会一下子变得直观（按 30 天计，1TB 分别取 10¹² 和 2⁴⁰ 字节两种口径）：

| 月流量配额 | 折合平均持续速率 |
| --- | --- |
| 500 GB | 约 1.5–1.7 Mbps |
| 1 TB | 约 3.1–3.4 Mbps |
| 2 TB | 约 6.2–6.8 Mbps |
| 5 TB | 约 15–17 Mbps |
| 10 TB | 约 31–34 Mbps |
| 30 TB | 约 92–101 Mbps |

端口当然不是没用。突发下载、多并发、单线程拉满，靠的都是它。但如果你的业务是持续推流、长期做大文件分发，或者拿它当镜像源，决定你多久被限速的是流量那一列，不是端口那一列。

## 除了端口，真正决定成本的三件事

### 流量只算出站，入站免费

官方明确：只计出站流量，入站完全不计费，配额在每个计费周期开始时重置。这直接改变两类业务的成本结构。

做数据采集、回源、备份、从境外拉内容的，入站免费等于省掉大头，1TB 配额能撑很久。做下载站、视频分发、镜像源的，出站压力全在配额上，端口再大也只是让你更快撞到天花板。

### 流量包统一定价 $0.06/GB，而且不结转

不够用可以自助买流量包：100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1,200。折算下来每一档都是 $0.06/GB，买大包没有单价优惠。

两个细节值得注意：流量包只对当期有效，不结转到下个月；官方自己的建议也是“长期不够用就升级套餐，别反复买包”。

算一下就知道为什么。HKG.Turin.Mini 的 1TB 配额如果不够，补 1TB 要 $60，而它的月费才 $69——补一次流量等于多付 87% 的钱。同样的 1TB 流量，HKG.Pulse.Mini 整台机器才 $59。买低配再补包，基本是亏的。

### 续费没有宽限期

官方文档用 caution 块强调了这条：到期日当天服务立即暂停，没有 grace period；逾期 5 天服务终止，数据可能无法恢复；逾期 6 天账单自动取消。续费账单在到期前 7 天生成并尝试自动扣款，逾期第 1、2、3 天各发一次提醒。

**建站、跑 API、月流量 1TB 以内。** 香港 HKG.Pulse.Mini，$59/月，2 核 4G、60G NVMe、1TB 流量、1Gbps 端口。要更便宜的入口就选 JPN.Pulse.Mini（$49）或 SIN.Pulse.Nano（$29），代价是延迟从官方口径的 <30ms 变成 <50ms 或 <70ms。

**单核性能敏感。** 游戏服、编译任务、实时接口，看的是单核而不是核数。HKG.Turin.Mini 用的 EPYC 9575F，2025 年 12 月一篇第三方实测里 Geekbench 5 单核 2259、多核 4262，fio 1M 块读写合计 8.03 GB/s。这个成绩放在共享 VPS 里算很靠前。同一位测评者的结论是“顶配硬件 + 极致线路 + 贵但值得”，同时也写了“预算有限的个人用户：买其他家”。

**要 5Gbps 端口又要 5TB 流量。** HKG.Turin.Pro，$299/月，6 核 16G / 180G NVMe / 5TB / 5Gbps。同档位 Pulse.Pro 是 $269 但端口只有 3Gbps，差 $30 换 2Gbps 端口，看你更在意哪个。

**移动用户为主。** 第三方实测里香港和日本方向的移动上行 QoS 比较明显：广东移动 1Gbps 拉香港，30 秒平均只有 37.5–38 Mbps，同一篇测评里另有 1Gbps 移动线路跑出 933 Mbits/sec 的对例，可见表现和具体线路关系很大。新加坡方向移动表现最好。电信和联通方向则相反，深圳电信单线程 475–478 Mbps、济南联通 545–572 Mbps，香港都很稳。如果访客以移动网络为主，新加坡值得优先考虑。

**不适合谁。** 想整月跑满端口的、需要真正不限流量的、打算长期满载跑计算的，都不太适合。官方写明：实例如果被判定为 noisy neighbor（持续高 CPU 影响同节点其他用户），可能被施加 CPU 性能节流作为惩罚。
